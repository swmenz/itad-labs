# Отчёт о качестве данных: Movie Industry (1980–2019)

## 1. Контекст

**Основной аналитический вопрос из [`Project Brief`](project_brief.md):** как в период четырёх полных десятилетий с 1980 по 2019 год (`[1980; 2020)`) различаются количество выпущенных фильмов, медианный коэффициент кассовой отдачи (`gross / budget`), доля кассово окупившихся картин (`gross >= budget`) и медианная оценка IMDb (`score`) в разрезе основных жанров (`genre`), возрастных категорий (`rating`) и десятилетий выпуска?

**Гранулярность:** одна строка исходного файла описывает один полнометражный кинофильм.

**Бизнес-ключ дедупликации:** отдельный числовой идентификатор релиза в наборе отсутствует, а названия у ремейков и одноимённых лент разных лет повторяются (*Hercules*, *The Lion King* и др.). Поэтому уникальность записи проверяется по составному ключу `(lower(trim(name)), year)`.

**Входной объект в слое `raw`:**

```text
s3://raw/movie_industry/ingested_on=2026-10-24/movies.csv
```

Логическая дата загрузки снимка через DAG `ingest_raw` — `2026-10-24` (`1 344 929` байт). Целевой аналитический период ограничен четырьмя полными десятилетиями `1980–2019` гг. по полю `year`.

## 2. Профиль

В исходном файле `movies.csv` содержится **7 668 строк** и **15 собственных полей** (в ноутбуке CSV читается с параметром `hive_partitioning = false`, чтобы DuckDB не добавлял техническое 16-е поле `ingested_on` из S3-префикса). Для профилирования до преобразований выбраны поля составного ключа (`name`, `year`) и ключевых метрик и срезов проекта; по каждому полю проверены все `7 668` строк:

| Поле | Тип DuckDB | Примеры значений | Проверено | Пропуски / доля | Смысл пропусков |
|---|---|---|---:|---:|---|
| `name` | `VARCHAR` | `'71`, `'Round Midnight` | 7 668 | 0 / 0,000 % | Пропусков нет |
| `year` | `BIGINT` | `1980`, `1981` | 7 668 | 0 / 0,000 % | Пропусков нет |
| `genre` | `VARCHAR` | `Action`, `Adventure` | 7 668 | 0 / 0,000 % | Пропусков нет (один основной жанр на фильм) |
| `rating` | `VARCHAR` | `Approved`, `G` | 7 668 | 77 / 1,004 % | Сертификат проката не указан на карточке IMDb |
| `score` | `DOUBLE` | `1.9`, `2.1` | 7 668 | 3 / 0,039 % | Нет пользовательского рейтинга у трёх релизов 2020 г. |
| `votes` | `DOUBLE` | `7.0`, `14.0` | 7 668 | 3 / 0,039 % | Нет голосов у тех же трёх релизов 2020 г. |
| `budget` | `DOUBLE` | `3000.0`, `5000.0` | 7 668 | 2 171 / 28,312 % | Производственный бюджет не раскрыт в открытых источниках |
| `gross` | `DOUBLE` | `309.0`, `596.0` | 7 668 | 189 / 2,465 % | Нет сведений о мировых кассовых сборах |
| `runtime` | `DOUBLE` | `55.0`, `63.0` | 7 668 | 4 / 0,052 % | Не заполнен хронометраж картины в карточке IMDb |

**Проверка повторов и временного покрытия:**

- Повторов составного бизнес-ключа `(lower(trim(name)), year)` — **0** (способ подсчёта: `count(*) - count(DISTINCT (lower(trim(name)), year))` среди строк с непустыми компонентами ключа). При этом одно название `lower(trim(name))` без учёта года повторяется **157** раз, что подтверждает необходимость составного ключа. Полных дубликатов строк по всем 15 полям (`count(*) - count(DISTINCT *)`) — **0**.
- Фактический диапазон года выпуска в `raw`: **`1980–2020`**.

**Распределение записей по десятилетиям и основным жанрам в `raw`:**

| Период (`year`) | Фильмов | | Основной жанр (`genre`) | Фильмов |
|---|---:|---|---|---:|
| `1980–1989` | 1 643 | | `Comedy` | 2 245 |
| `1990–1999` | 2 000 | | `Action` | 1 705 |
| `2000–2009` | 2 000 | | `Drama` | 1 518 |
| `2010–2019` | 2 000 | | `Crime` | 551 |
| `2020` (вне полных десятилетий) | 25 | | `Biography` | 443 |
| **Всего** | **7 668** | | Остальные жанры (14 категорий) | 1 206 |

**Значимые наблюдения:**

1. **Неполное десятилетие на правой границе набора:** каждое из полных десятилетий `1980–2019` представлено `1 643–2 000` фильмами, тогда как на `2020` год приходится лишь `25` релизов начала следующего десятилетия `[2020; 2030)` (включая все 3 пропуска оценок и голосов). Смешивание 2020 года с полными декадами исказило бы межвременные сравнения, поэтому такие строки подлежат изоляции в карантин.
2. **Структурный характер пропусков финансовых полей и неоднородность `rating`:** отсутствие `budget` (`28,312 %`) или `gross` (`2,465 %`, совокупно неполная пара у `2 232` фильмов — `29,108 %`) означает нераскрытую коммерческую отчётность, а в `rating` помимо 77 пропусков присутствуют 354 записи с внерейтинговыми и телевизионными метками (`Not Rated`, `Unrated`, `TV-MA`, `X` и др.). Отправка этих записей в карантин лишила бы анализ почти трети каталога при подсчёте числа релизов и `median(score)` по жанрам, поэтому для них выбрана маркировка флагом (`flag`).

## 3. Правила и результаты

Полные паспорта правил, критичность, связь с метриками `Project Brief` и SQL-запросы приведены в разделе «Шаг 3» [ноутбука](../notebooks/profile_quality.ipynb#rules). Пороги заданы целочисленными переменными (`count <= 0`) в ячейках кода каждого правила:

| Правило (`id`) | Проверено | Нарушений | Доля | Порог | Сравнение | Действие |
|---|---:|---:|---:|---|---|---|
| `unique_movie_key` | 7 668 | 0 | 0,000 % | `count <= 0` | Не превышен | `quarantine` |
| `year_in_study_period` | 7 668 | 25 | 0,326 % | `count <= 0` | Превышен | `quarantine` |
| `valid_score_and_votes` | 7 668 | 3 | 0,039 % | `count <= 0` | Превышен | `quarantine` |
| `positive_runtime` | 7 668 | 4 | 0,052 % | `count <= 0` | Превышен | `quarantine` |
| `complete_positive_financials` | 7 668 | 2 232 | 29,108 % | `count <= 0` | Превышен | `flag` |
| `standard_mpaa_rating` | 7 668 | 431 | 5,621 % | `count <= 0` | Превышен | `flag` |

**Обоснование принятых решений:**

- Нарушения правил `year_in_study_period` (25 фильмов 2020 г.), `valid_score_and_votes` (3 фильма без оценки и голосов) и `positive_runtime` (4 фильма с `runtime IS NULL`, включая 3 релиза 2010–2012 гг.: *Saw: The Final Chapter*, *The Wolfman*, *One for the Money*) исключаются в карантин, так как выходят за рамки полных десятилетий `1980–2019` либо не позволяют рассчитать рейтинговые и хронометражные метрики без восстановления значений по догадке.
- Неполные финансовые пары (`complete_positive_financials`) и нестандартные/пустые возрастные сертификаты (`standard_mpaa_rating`) сохраняются в `staging` с булевыми флагами: на этапе построения витрин это позволяет включать все `7 640` валидных фильмов 1980–2019 гг. в расчёт количества релизов и `median(score)`, но фильтровать подмножества для `gross / budget` и возрастных категорий MPAA. Из `2 232` финансовых и `431` рейтингового предупреждений в `raw` под критический карантин попали `19` и `12` записей соответственно, поэтому в `staging` остаются **`2 213`** и **`419`** помеченных строк.

## 4. Подготовленные данные

**Выходные пути в бакете `staging` SeaweedFS:**

```text
s3://staging/movie_industry/source_ingested_on=2026-10-24/staging.parquet
s3://staging/movie_industry/source_ingested_on=2026-10-24/quarantine.parquet
```

**Фактические преобразования и добавленные признаки:**

- В `staging.parquet` (`17` полей) строковые поля очищены от краевых пробелов с переводом пустых строк в `NULL` (`NULLIF(trim(...), '')`), целочисленные по смыслу атрибуты приведены к целым типам (`year` → `INTEGER`, `votes` → `BIGINT`, `runtime` → `INTEGER`), вещественные — к `DOUBLE` (`score`, `budget`, `gross`). Бизнес-агрегации и производные показатели (`gross / budget`) в `staging` не рассчитываются.
- Добавлены два булевых признака предупреждений:
  - `quality_incomplete_financials` (`BOOLEAN`): `true`, если `budget` или `gross` отсутствуют либо неположительны (`2 213` строк в `staging`), иначе `false`;
  - `quality_nonstandard_rating` (`BOOLEAN`): `true`, если `rating` пуст или не входит в шкалу MPAA `G`, `PG`, `PG-13`, `R`, `NC-17` (`419` строк в `staging`), иначе `false`.
- В `quarantine.parquet` (`17` полей) сохранены все 15 исходных полей `raw` без изменений, а также строковые колонки `quality_rule_ids` (перечисление всех сработавших критических `id` через `;` без завершающего разделителя, например `year_in_study_period;valid_score_and_votes`) и `quarantine_reason` (читаемое описание причин через `; `).

**Баланс строк и проверка сохранённых файлов из S3:**

- Баланс строк сошёлся точно: **`7 668 (raw) = 7 640 (staging) + 28 (quarantine)`**. Четыре фильма 2020 года нарушили сразу по два критических правила (`3` — период и оценку/голоса, `1` — период и `runtime`), но записаны в карантин по одному разу со всеми причинами исключения.
- При повторном чтении `staging.parquet` и `quarantine.parquet` напрямую из S3 подтверждено: критических нарушений в `staging` — **0** (включая `0` дубликатов ключа `(name, year)`), расхождений обоих булевых флагов — **0**, пустых причин в карантине — **0**, размер (`1 344 929` байт) и `ETag` исходного объекта в `raw` не изменились.
